# Pages and addresses

Open **Pages** in the rail on the left.

- **Add a page**: give it a title and an address like `/about`. Start from a blank page or from a template — Landing, About us, Services, Pricing, Contact, Gallery.
- **Show in the main menu** puts the page into the site's navigation.
- **App shell** is what sits around every page: the header with the menu, and the footer. Edit it like any page.
- **Search title**, **Search description** and **Share image** are what search engines and social networks show. **Whole site** sets the title pattern and the language.

An address with a part like `/events/:slug` makes a page that shows one item — see *Lists and detail pages*.
