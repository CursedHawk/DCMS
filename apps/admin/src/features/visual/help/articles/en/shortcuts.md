# Keyboard shortcuts

With a part selected on the page:

- **Esc** — select the part around it
- **Ctrl/⌘ D** — duplicate
- **Alt ↑** / **Alt ↓** — move it up or down
- **Del** — delete
- **Ctrl/⌘ C**, **Ctrl/⌘ V** — copy and paste
- **Ctrl/⌘ Alt C**, **Ctrl/⌘ Alt V** — copy and paste its style
- **Ctrl/⌘ Z**, **Ctrl/⌘ ⇧ Z** — undo and redo
- **Double-click** — type into a text
- **Right-click** — everything else

Press **?** on the page to see them all.
