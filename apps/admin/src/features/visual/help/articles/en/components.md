# Reusable components

Build something once — a card, a banner, a team member — and use it on many pages.

- **Make one**: right-click a part and choose **Make reusable…** It opens in the **component studio**.
- In the studio, choose **Settings** pages may change (a title, a picture, a link) and **Slots** — empty areas each page fills with its own parts. **Preview** shows it on a computer, tablet and phone; **Done** takes you back.
- Your components are in **My components**, and in the palette under **Mine**.

**Versions.** Each page keeps the version it was placed with. Editing a component that pages use starts the next version, so nothing changes under them. When you are ready, **Update all** moves every page to the newest version.
