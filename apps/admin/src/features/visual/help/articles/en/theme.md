# The look of the site

Open **Theme** in the rail.

1. Pick a **design kit**: a complete set of colours, fonts, corners and spacing. Every part on every page follows it.
2. Adjust it: the **brand** and **accent** colours, the fonts for headings and text, how round the corners are, how much space there is, how strong the shadows are.

If a colour makes text hard to read, a warning says so.

**Reset to kit** takes back every adjustment. Choosing another kit starts again from that kit.
