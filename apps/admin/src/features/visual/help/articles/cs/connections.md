# Obsah z jiných služeb

**Propojení** přináší data z API jiné služby — vstupenky, rezervace, katalog produktů.

1. V administraci otevřete **Propojení** a přidejte ho: základní URL, klíč a operace (cesty), které se mají načítat.
2. DCMS je načítá podle plánu a odpovědi ukládá. Klíč je šifrovaný a nikdy se nedostane do prohlížeče.
3. V editoru se operace propojení objeví jako **obsah** pro Collection nebo detailní stránku, stejně jako obsah pluginu.

**Obnovit nyní** u propojení načte nejnovější data hned.
