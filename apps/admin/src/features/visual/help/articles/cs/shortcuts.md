# Klávesové zkratky

S vybranou částí na stránce:

- **Esc** — vybrat část kolem
- **Ctrl/⌘ D** — zdvojit
- **Alt ↑** / **Alt ↓** — posunout nahoru nebo dolů
- **Del** — smazat
- **Ctrl/⌘ C**, **Ctrl/⌘ V** — kopírovat a vložit
- **Ctrl/⌘ Alt C**, **Ctrl/⌘ Alt V** — kopírovat a vložit styl
- **Ctrl/⌘ Z**, **Ctrl/⌘ ⇧ Z** — zpět a znovu
- **Dvojklik** — psát do textu
- **Pravé tlačítko** — vše ostatní

Stiskněte **?** na stránce a uvidíte je všechny.
