# Vzhled webu

V liště otevřete **Vzhled**.

1. Vyberte **designovou sadu**: ucelené barvy, písma, zaoblení a rozestupy. Řídí se jí každá část na každé stránce.
2. Upravte ji: **hlavní** a **doplňkovou** barvu, písma nadpisů a textu, zaoblení rohů, množství prostoru a sílu stínů.

Pokud by barva zhoršila čitelnost textu, upozornění to řekne.

**Vrátit sadu** vrátí všechny úpravy. Výběr jiné sady začne znovu od ní.
