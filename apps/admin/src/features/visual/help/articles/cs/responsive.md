# Počítač, tablet a telefon

Tři tlačítka nahoře ukážou stránku tak širokou jako počítač, tablet nebo telefon.

Nastavení změněná při zvoleném **počítači** platí všude. Změníte-li nastavení při zvoleném **tabletu** nebo **telefonu**, platí jen pro tu velikost a menší — nastavení se označí jako odlišné a **jako počítač** ukazuje, kde se stále řídí počítačem.

Odlišnost zrušíte tlačítkem pro obnovení vedle nastavení.

Většina rozvržení se přizpůsobí sama: Grid nebo Split na telefonu dá sloupce pod sebe. Před publikováním si každou stránku prohlédněte na telefonu.
