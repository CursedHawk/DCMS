# Tenant API

Generated by DCMS from this tenant's plugins. **Do not edit** — this folder is rewritten
whenever the tenant's plugins change. Read this file instead of `openapi.json`: it lists
every call the typed client offers.

```ts
import { createTenantClient, collections, forms } from './api'; // path relative to src/
const api = createTenantClient({ baseUrl: import.meta.env.VITE_API_BASE_URL ?? '' });
```

Lists return `{ items, page, pageSize, totalCount }`; each item is `{ id, slug, data, publishedAt }`
with the typed fields under `data`. Media fields hold asset ids — pass them to `api.media.url`.
Failed calls throw `ApiError` with `status` and `body`. Exact field types are in `types.ts`.

## Calls

### Built in

Available on every tenant.

- `api.media.url(assetId, variant?)` → `string` — URL of a media asset. Images: webp-320, webp-640, webp-960, webp-1280, webp-1920, thumb, original. Video: hls-master. (GET /api/media/{assetId}/{variant})
- `api.content(instance, contentType).list(params?) / .get(slug)` → `PagedResult / ContentItem` — Untyped access to any collection by slug — what `collections` is for. (GET /api/{instance}/{contentType})
- `api.submitForm(instance, formName, values)` → `SubmissionResult` — Submit any form in `forms` without knowing its slug. (POST /api/{instance}/forms/{name})
- `api.call(method, path, { query?, body? })` → `Promise<T>` — Any operation in openapi.json, for one this file has no accessor for. (any)
- `api.tags.list(params?)` → `TagIndex` — Tags in use across every collection, most used first. Filter any list with { tag }. (GET /api/tags)

### Brand (`brand`)

Public branding for the site header.

- `api.brand.identity.get()` → `{ name: string | null; tagline: string | null; logoUrl: string | null; logoDarkUrl: string | null; faviconUrl: string | null; primaryColor: string | null; secondaryColor: string | null; items: Record<string, string> }` — The public branding: name, tagline, logo, favicon, colours and public items. (POST /api/brand/_contracts/branding.identity@1/Get)
- `api.brand.branding.get()` → `BrandBranding` — Get public branding (GET /api/brand/branding)

### Enquiries (`enquiries`)

Visitor enquiries from the website.

- `api.enquiries.forms.contact.submit(body)` → `{ submissionId: string; message: string }` — Submit the Contact us form (POST /api/enquiries/forms/contact)

### Search (`find`)

Site search.

- `api.find.search({ q, limit? })` → `SearchResult` — Full-text search across searchable content. (GET /api/find/search)

### Members (`members`)

Member accounts.

- `api.members.auth.register(body) / .login(body) / .refresh(token) / .me() / .getProfile() / .updateProfile(update)` → `VisitorTokens / VisitorProfile / VisitorOwnProfile` — Visitor accounts and profiles. Pass `visitorToken` to createTenantClient for `me()` and the profile calls. (POST /api/members/register|login|refresh, GET /api/members/me, GET|PUT /api/members/me/profile)
- `api.members.identity.getCurrent()` → `{ visitor: { id: string; email: string; displayName: string | null; attributes: Record<string, unknown>; createdAt: string } | null }` — The signed-in visitor, with the attributes visible to plugins; null when nobody is signed in. (POST /api/members/_contracts/visitors.identity@1/GetCurrent)
- `api.members.profiles.getPublic(body)` → `{ id: string; displayName: string | null; attributes: Record<string, unknown> } | null` — A visitor's public profile: display name and public attributes only. (POST /api/members/_contracts/visitors.profiles@1/GetPublic)

### News (`news`)

Company announcements and product updates.

- `api.news.posts.get(body)` → `{ id: string; instanceId: string; slug: string; publishedAt: string; data: { title: string; excerpt: string | null; body: string; coverImage: string | null; tags: string[] | null } } | null` — One published post by slug. (POST /api/news/_contracts/blog.posts@1/Get)
- `api.news.posts.list(body)` → `{ items: ({ id: string; instanceId: string; slug: string; publishedAt: string; data: { title: string; excerpt: string | null; body: string; coverImage: string | null; tags: string[] | null } })[]; page: number; pageSize: number; totalCount: number }` — Published posts, newest first. (POST /api/news/_contracts/blog.posts@1/List)
- `api.news.post.list({ page?, pageSize?, tag? })` → `PagedResult<NewsPost>` — List post items (GET /api/news/post)
- `api.news.post.get(slug)` → `ContentItem<NewsPost>` — Get a post by slug (GET /api/news/post/{slug})

### Stats (`stats`)

Anonymous analytics.

- `api.stats.collect(event)` → `void` — Record an analytics event. Prefer src/dcms: it handles consent. (POST /api/stats/collect)

### Support (`support`)

Support chat.

- `api.support.chat.history(conversationId)` → `ChatMessage[]` — Messages of one chat conversation. (GET /api/support/chat/conversations/{id}/messages)
